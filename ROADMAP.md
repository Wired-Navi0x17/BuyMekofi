# Roadmap

Each milestone ends the same way: tests pass, docs and `progress.md` are updated, there's a security pass over the diff, and a commit is made and pushed. A milestone is not complete because its UI exists. It is complete when its acceptance checks pass.

Reordered on 2026-11-07. The founder asked for (a) pages that can be designed into a full personal site (PAGE_STUDIO.md) and (b) an admin CMS to control the site, so both move ahead of payments.
