# Coffea et Thea

A creator page and support platform for India: one page with your links, your portfolio and a way for your audience to pay you.

**Status:** in development. No real payments are processed. See `progress.md`.

```bash
pnpm install
cp .env.example .env.local   # fill in values; never commit
pnpm dev
```

Read `PRD.md` and `ARCHITECTURE.md` first, then `CLAUDE.md` for working rules.
